# Mentor-Interactive
WNDR Museum DUPE, musical interactive

# Pin Assignments per Sensor 

**Potentiometer** : 115200, printing char values 0, 1 or 2</br>
**Distance** : 9600, printing string values "NEAR" or "FAR"</br>
**Switch** : 4800, printing string values "ON" or "OFF"</br>
**Accelerometer** : 38400, printing char values "T" or "F"</br>
**Button** : 74880, printing char P for pressed NP for not pressed </br>
