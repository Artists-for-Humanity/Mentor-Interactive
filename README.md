# Mentor-Interactive
WNDR Museum DUPE, musical interactive

# Serial Assignments per Sensor 

**Potentiometer** : 115200, printing char values 0, 1 or 2</br>
**Distance** : 9600, printing string values "C" for CLOSE or "X" for FAR</br>
**Switch** : 4800, printing string values "Y" or "N"</br>
**Accelerometer** : 38400, printing char values "T" or "F"</br>
**Button** : 74880, printing char P for pressed W for not pressed </br>

# Key Assignments per Sensor 

'p' Potentiometer
'd' Distance"
's' Switch
'a' Accelerometer
'b' "Button"
